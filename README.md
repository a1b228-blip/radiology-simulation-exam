# 醫事放射 13 大臨床高階陷阱題與實戰應變破解全指南

本專案專門提供醫策會與各級醫院「醫事放射情境模擬競賽 / 上機考核」之臨床陷阱題型解析與應變 SOP 指南。

## 🎯 涵蓋題型
### 📷 一般 X 光篇 (7 大陷阱)
1. 隱匿性鎖骨骨折（急診主動通報警訊值）
2. 全身性器官鏡像反轉／右心症（解剖標記 vs 左右鉛字驗證）
3. 側邊隱匿性張力性氣胸（縱隔腔位移與胸管引流準備）
4. 氣管內管過深（隆突 Carina 距離量測與重新調整）
5. 影像左右標記（Marker）顛倒錯單核對
6. 虛弱長者胸部立位照相跌倒防範
7. 隱藏衣物亮片金屬鈕扣之假影判別

### 🖥️ 電腦斷層 CT 篇 (6 大陷阱)
8. 頭部斷層金屬活動假牙嚴重星狀假影
9. 高壓注射顯影劑 24G 軟針外滲急症處置
10. 糖尿病服用 Metformin 隱匿性腎損傷評估
11. 主動脈血管攝影 Stanford Type A 急性主動脈剝離危急判讀
12. 候診區同名同姓病人錯單推進掃描室攔截
13. 檢查結束後等候區延遲性過敏性休克處置
